# شركة الإخلاص للتوظيف والحلول الإدارية
### Al-Ekhlas Recruitment & Management Solutions Web Platform

منصة رقمية متكاملة لخدمات التوظيف والاستقطاب المهني والتنفيذي (B2B / B2C) مع لوحة تحكم إدارية متقدمة ومطابق ذكي للكوادر (AI Smart Matchmaker)، مبنية بأحدث تقنيات الويب.

---

## 🚀 التقنيات المستخدمة (Tech Stack)

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (Dark / Light Mode)
- **Animations**: Framer Motion & Canvas Confetti
- **Icons**: Lucide React
- **Internationalization (i18n)**: دعم كامل وثنائي للغتين العربية (RTL) والإنجليزية (LTR)

---

## 🌟 مميزات المنصة الرئيسية

### 🌐 1. الموقع العام وبوابات التقديم
- **الصفحة الرئيسية (Landing Page)**: استعراض إحصائيات حية، الخدمات الست الرئيسية، مسار العمل، وآراء العملاء.
- **بوابة أصحاب الأعمال (For Employers)**: نموذج تفاعلي من 3 خطوات لتسجيل احتياجات التوظيف ورفع الوصف الوظيفي.
- **بوابة الباحثين عن عمل (For Job Seekers)**: نموذج تسجيل السير الذاتية، التخصصات، والروابط المهنية (LinkedIn / Portfolio).
- **مركز الفروع والتواصل**: مكاتب الرياض، القاهرة، ودبي مع تكامل فوري لمحادثات الواتساب.

### 🛡️ 2. لوحة التحكم الإدارية (`/admin`)
- **لوحة التحليلات (Dashboard Overview)**: مؤشرات أداء حية (KPIs)، مخطط خط التوظيف الفعلي (Pipeline)، وتوزيع الطلبات حسب القطاعات.
- **إدارة طلبات الشركات (Employer Orders)**: جدول بيانات متقدم لفرز الطلبات، تحديث الحالات، وتخصيص المرشحين.
- **قاعدة الكفاءات (Candidate Pool)**: استعراض السير الذاتية (CV Viewer)، التقييم النجمي، ومحرر ملاحظات HR السرية.
- **المطابق الذكي (AI Smart Matchmaker)**: حساب نسبة التوافق (% Match Score)، إعداد القوائم المختصرة (Shortlists)، وتصدير وطباعة ملفات الترشيح للعملاء.
- **نظام التنبيهات الفورية (Live Toast Center)**: إشعارات حية ومزامنة فورية للطلبات الجديدة في الجداول.
